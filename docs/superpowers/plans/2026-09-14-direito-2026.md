# Direito 2026 Implementation Plan

**Goal:** Publicar um acervo de estudos com cinco disciplinas e índices automáticos.

**Architecture:** Node.js nativo gera páginas estáticas a partir dos HTML nas pastas. GitHub Actions publica a pasta `_site`; os materiais de origem são preservados.

**Tech Stack:** HTML, CSS, Node.js, node:test, GitHub Actions / Pages.

**Spec:** `docs/projeto.md`, com requisitos aprovados na conversa.

## Global Constraints

- Português brasileiro; nome Direito 2026; repositório público direito-2026.
- Cinco disciplinas fixas; três HTML existentes em Constitucional.
- Links relativos; sem bibliotecas externas; responsivo; sem mudança no conteúdo dos estudos.

## Execução

- [ ] Descoberta: `scripts/catalog.mjs` exporta `SUBJECTS` e `collectSubjects(root)`; testes em `tests/catalog.test.mjs` cobrem alterações na pasta e leitura de metadados.
- [ ] Páginas: `scripts/render.mjs` renderiza início e disciplina; `assets/estilos.css` define a interface. `scripts/build.mjs` gera os índices e copia apenas o conteúdo público para `_site`.
- [ ] Publicação: `.github/workflows/pages.yml` executa `npm test`, `npm run build` e o deploy oficial do Pages. `README.md` ensina upload de materiais e configuração inicial.
- [ ] Verificação: `node --test`, `node scripts/build.mjs`, integridade dos três HTML, links sob `/direito-2026/`, inspeção visual em 1440px e 390px.
- [ ] Entrega: prévia local; criação e publicação remota quando o login do GitHub estiver disponível.
